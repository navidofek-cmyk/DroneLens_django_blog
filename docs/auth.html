🔐 Autentizace — JWT

Kompletní popis JWT flow: jak backend vydává tokeny a jak frontend automaticky obnovuje přístup.

Jak JWT funguje

DroneLens používá JSON Web Tokens (JWT) přes knihovnu djangorestframework-simplejwt.

Po přihlášení server vydá dva tokeny:

TokenPlatnostÚčelUložení
access5 minutAutorizace API požadavkůlocalStorage
refresh7 dníZískání nového access tokenulocalStorage
Bezpečnostní poznámka Ukládání JWT do localStorage je citlivé na XSS útoky. Pro produkční aplikace zvažte httpOnly cookies. Pro výukový projekt je localStorage dostačující.

Backend konfigurace (settings.py)

SIMPLE_JWT = {
    'ACCESS_TOKEN_LIFETIME':  timedelta(minutes=5),
    'REFRESH_TOKEN_LIFETIME': timedelta(days=7),
    'ROTATE_REFRESH_TOKENS':  False,
    'ALGORITHM': 'HS256',
    'AUTH_HEADER_TYPES': ('Bearer',),
}

Axios interceptor (frontend)

Soubor frontend/src/api/axios.js vytváří Axios instance s automatickým JWT flow:

// 1. Před každým požadavkem — přidá Authorization header
axiosInstance.interceptors.request.use(config => {
  const token = localStorage.getItem('access')
  if (token) config.headers.Authorization = `Bearer ${token}`
  return config
})

// 2. Po každé chybě 401 — pokusí se obnovit token
axiosInstance.interceptors.response.use(
  res => res,
  async err => {
    if (err.response?.status === 401 && !err.config._retry) {
      err.config._retry = true
      try {
        const refresh = localStorage.getItem('refresh')
        const { data } = await axios.post('/api/auth/refresh/', { refresh })
        localStorage.setItem('access', data.access)
        err.config.headers.Authorization = `Bearer ${data.access}`
        return axiosInstance(err.config)   // opakuj původní požadavek
      } catch {
        localStorage.removeItem('access')
        localStorage.removeItem('refresh')
        window.location.href = '/login'    // přesměruj na login
      }
    }
    return Promise.reject(err)
  }
)

AuthContext (React)

Soubor frontend/src/context/AuthContext.jsx spravuje stav přihlášeného uživatele:

// Při mountu — načte uživatele pokud je v localStorage access token
useEffect(() => {
  const token = localStorage.getItem('access')
  if (token) {
    axiosInstance.get('/api/auth/me/')
      .then(res => setUser(res.data))
      .catch(() => setUser(null))
  }
}, [])

// login — uloží tokeny, nastaví user
const login = async (username, password) => {
  const { data } = await axiosInstance.post('/api/auth/login/', { username, password })
  localStorage.setItem('access', data.access)
  localStorage.setItem('refresh', data.refresh)
  const me = await axiosInstance.get('/api/auth/me/')
  setUser(me.data)
}

// logout — smaže tokeny
const logout = () => {
  localStorage.removeItem('access')
  localStorage.removeItem('refresh')
  setUser(null)
}

Rate limiting na auth endpointech

Chráníme auth endpointy před brute-force útoky pomocí DRF throttling:

class LoginRateThrottle(AnonRateThrottle):
    rate = '10/min'   # max 10 pokusů o přihlášení za minutu z jedné IP

class RegisterRateThrottle(AnonRateThrottle):
    rate = '5/hour'   # max 5 registrací za hodinu z jedné IP
Bypass v testech Backend testy dekorují testovací třídy pomocí @override_settings(REST_FRAMEWORK={...}) který vypne throttling. Viz soubor blog/tests.py — dekorátor @NO_THROTTLE.
