Stránky

PostList pages/PostList.jsx

Homepage — seznam publikovaných článků s hero kartou prvního příspěvku.

  • Data: useQuery(['posts', params]) → GET /api/posts/
  • Filtry: search (URL param ?search=), category slug, tag slug
  • Loading: CSS skeleton karty (.skeleton)
  • Error: "Failed to load posts" alert
  • Empty: "No posts found" zpráva
  • Sidebar: seznam kategorií a tagů (useQuery)
  • Hero card: první článek zobrazí velký banner s drone meta info
// Ukázka drone meta bloku v PostList
<div className="drone-meta">
  <i className="bi bi-geo-alt-fill"></i> {post.location}
  <i className="bi bi-arrow-up-circle"></i> {post.altitude} m
  <i className="bi bi-camera"></i> {post.drone_model}
</div>

PostDetail pages/PostDetail.jsx

Detailní pohled na článek. Načítá slug z useParams().

  • Data: useQuery(['post', slug]) → GET /api/posts/{slug}/
  • Drone meta box: lokace, výška, model dronu (pokud jsou vyplněny)
  • Fotogalerie: mřížka fotek s lightbox efektem (onclick → fullscreen)
  • Komentáře: seznam + formulář pro přihlášené uživatele
  • Editace: tlačítka Edit / Delete viditelná pouze autorovi (user.id === post.author?.id)
  • Error 404: "Failed to load / nenalezen" zpráva

PostForm pages/PostForm.jsx

Formulář pro vytváření i editaci článku. Detekuje edit mode z URL (:slug).

  • Odesílá multipart/form-data kvůli nahrávání obrázků
  • Pole: title, content (textarea), excerpt, category (select), tags_input, status, cover_image
  • Drone meta pole: location, altitude, drone_model
  • Po úspěšném create přesměruje na /post/{slug}

PhotoUploadPage pages/PhotoUploadPage.jsx

Wrapper stránka pro PhotoUploader komponentu. Chráněná routou — pouze autor článku.

MyPosts pages/MyPosts.jsx

Tabulka vlastních článků přihlášeného uživatele.

  • Sloupce: Titulek, Stav (badge), Datum, Akce (Edit, Photos, Delete)
  • Přesměrovává na /login pokud není přihlášen
  • Empty state: text o prvním článku

Login / Register

Formuláře autentizace. Register validuje shodu hesel na klientovi před odesláním.

PhotoUploader components/PhotoUploader.jsx

Drag & drop upload s automatickým čtením EXIF dat z drone fotek.

  • Drop zone: přijímá JPEG/PNG přetažením nebo výběrem
  • EXIF čtení: knihovna exifr extrahuje GPS souřadnice, nadmořskou výšku a model kamery
  • Preview: miniatura každé fotky s caption inputem
  • Status: ikona stavu (nahrávání ⟳ / hotovo ✓ / chyba ✗) pro každý soubor
  • Upload: každý soubor nahrán samostatně přes POST /api/posts/{slug}/photos/
// EXIF čtení z drone fotky

const exifData = await exifr.parse(file, {
  gps: true,
  tiff: true,
  exif: true,
})
// exifData.latitude, exifData.longitude, exifData.GPSAltitude, exifData.Model

Kontext — AuthContext

Soubor context/AuthContext.jsx — globální auth stav dostupný přes hook useAuth().

ExportTypPopis
userobjekt nebo nullAktuálně přihlášený uživatel (id, username, email…)
loadingbooleanTrue dokud se nezjistí stav přihlášení
login(username, password)async functionPřihlásí uživatele, uloží tokeny
register(data)async functionZaregistruje a přihlásí
logout()functionSmaže tokeny, nastaví user=null
 
// Použití v komponentě
import { useAuth } from '../context/AuthContext'

function Navbar() {
  const { user, logout } = useAuth()
  return user
    ? <button onClick={logout}>Odhlásit ({user.username})</button>
    : <Link to="/login">Login</Link>
}

Data fetching — TanStack Query

Veškeré GET požadavky probíhají přes @tanstack/react-query (v5):

// Načtení seznamu článků
const { data, isLoading, isError } = useQuery({
  queryKey: ['posts', { search, category, tag, page }],
  queryFn: () => axiosInstance.get('/api/posts/', { params }).then(r => r.data),
  staleTime: 1000 * 60 * 5,  // cache 5 minut
})

// Invalidace po vytvoření/editaci
const queryClient = useQueryClient()
queryClient.invalidateQueries({ queryKey: ['posts'] })

POST/PATCH/DELETE operace jdou přímo přes axios (bez Query mutací — jednodušší implementace).
