Lokální vývoj (bez Dockeru)

1. Backend

# Klonování repozitáře
git clone https://github.com/your-org/django_blog.git
cd django_blog

# Instalace závislostí přes UV (vytvoří .venv automaticky)
uv sync

# Inicializace DB
uv run python manage.py migrate

# Vytvoření admin účtu
uv run python manage.py createsuperuser

# Spuštění na portu 8001
uv run python manage.py runserver 8001
Poznámka Backend API je dostupné na http://localhost:8001/api/. Admin rozhraní: http://localhost:8001/admin/.

2. Frontend

cd frontend
npm install
npm run dev

Vite spustí vývojový server na http://localhost:5173 (nebo :5174 pokud je port obsazený). Všechny požadavky na /api/* a /media/* jsou automaticky proxovány na backend.

Síťový přístup Pokud chcete přistupovat z jiného zařízení v síti (telefon, tablet), použijte IP adresu místo localhost: http://192.168.x.x:5173. Vite proxy automaticky přesměruje API na backend.

3. Env proměnné (volitelné pro vývoj)

# Zkopírujte šablonu
cp .env.example .env

# .env pro lokální vývoj
DJANGO_SECRET_KEY=my-local-dev-key-not-for-production
DEBUG=True

Docker — vývojový stack

# Spuštění celého stacku (PostgreSQL + Django + Vite)
docker compose up --build

# V jiném terminálu — apply migrace
docker compose exec backend uv run python manage.py migrate
docker compose exec backend uv run python manage.py createsuperuser

Stack spustí:

  • db — PostgreSQL 16 na portu 5432 (interní)
  • backend — Django na portu 8555
  • frontend — Vite dev server na portu 5173
Env soubor pro Docker Docker Compose načítá .env ze root adresáře. Minimálně nastavte DJANGO_SECRET_KEY a DB_PASSWORD.

Vytvoření testovacího uživatele

# Lokální vývoj
uv run python manage.py shell -c "
from django.contrib.auth.models import User
User.objects.create_superuser('ivan_dron', 'ivan@dron.cz', 'dron1234')
print('Hotovo!')
"

# Docker
docker compose exec backend uv run python manage.py shell -c "
from django.contrib.auth.models import User
User.objects.create_superuser('ivan_dron', 'ivan@dron.cz', 'dron1234')
"
Výchozí testovací účet V tomto projektu byl vytvořen účet ivan_dron / dron1234 — pouze pro lokální vývoj, nikdy do produkce.

Spuštění testů

Backend testy

uv run pytest              # všechny testy
uv run pytest -v           # verbose
uv run pytest --cov        # s coverage reportem (99 %)

Frontend testy

cd frontend
npm test                   # jednorázově
npm run test:watch         # watch mode
npm run test:coverage      # s pokrytím
