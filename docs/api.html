📡 API Reference

Kompletní přehled všech REST endpointů. Base URL: http://localhost:8001/api/ (dev) nebo https://your-domain.com/api/ (prod).

Skupiny endpointů Autentizace Články Komentáře Fotky Kategorie & Tagy Formáty odpovědí
Kliknutím rozbalte endpoint Každý blok níže obsahuje parametry, příklady požadavku a odpovědi. Kliknutím na hlavičku zobrazíte detail.

🔐 Autentizace

POST /api/auth/register/ Registrace nového uživatele Veřejný ▶

Rate limit

5 registrací / hodinu / IP adresu (RegisterRateThrottle).

Request body (JSON)

{
  "username": "ivan_dron",
  "email": "ivan@dron.cz",
  "password": "tajne_heslo",
  "password2": "tajne_heslo",
  "first_name": "Ivan",      // volitelné
  "last_name": "Novak"       // volitelné
}

Response 201 Created

{
  "id": 1,
  "username": "ivan_dron",
  "email": "ivan@dron.cz",
  "first_name": "Ivan",
  "last_name": "Novak",
  "full_name": "Ivan Novak"
}

Response 400 — chyby validace

{
  "password": ["Hesla se neshodují."]
}
POST /api/auth/login/ Přihlášení — vrátí JWT tokeny Veřejný ▶

Rate limit

10 pokusů / minutu / IP adresu (LoginRateThrottle).

Request body

{
  "username": "ivan_dron",
  "password": "tajne_heslo"
}

Response 200 OK

{
  "access": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "refresh": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
}

Access token platnost: 5 minut. Refresh token: 7 dní.

POST /api/auth/refresh/ Obnovení access tokenu Refresh token ▶

Request body

{ "refresh": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." }

Response 200 OK

{ "access": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." }
GET /api/auth/me/ Aktuálně přihlášený uživatel Vyžaduje JWT ▶

Headers

Authorization: Bearer <access_token>

Response 200 OK

{
  "id": 1,
  "username": "ivan_dron",
  "email": "ivan@dron.cz",
  "first_name": "Ivan",
  "last_name": "Novak",
  "full_name": "Ivan Novak"
}

POST /api/posts/ Vytvoření nového článku Vyžaduje JWT ▶

Odesílejte jako multipart/form-data (kvůli cover_image).

Request fields

PoleTypPovinnéPopis
titlestring✓Název článku
contentstring✓Text článku
excerptstringKrátký úryvek
cover_imagefileTitulní fotka
categoryint (ID)ID kategorie
tags_inputstringTagy oddělené čárkami: "DJI, Praha, Léto"
statusstringdraft (default) nebo published
locationstringMísto focení
altitudeintVýška v metrech
drone_modelstringModel dronu

Response 201 Created

Vrátí nový objekt pomocí PostWriteSerializer.

PATCH /api/posts/{slug}/ Aktualizace článku (pouze autor nebo staff) Vyžaduje JWT ▶

Odešlete pouze pole, která chcete změnit. Stejný formát jako při vytváření (multipart/form-data).

Response 403 — cizí článek

{ "detail": "Nemáte oprávnění." }
DELETE /api/posts/{slug}/ Smazání článku (pouze autor nebo staff) Vyžaduje JWT ▶

Response: 204 No Content

GET /api/posts/my/ Moje články (drafty i publikované) Vyžaduje JWT ▶

Vrátí stránkovaný seznam článků přihlášeného uživatele — včetně draftů.

📸 Fotky (galerie)

POST /api/posts/{slug}/photos/ Nahrání fotky do galerie článku Autor článku ▶

Odesílejte jako multipart/form-data. Pouze autor článku může nahrávat.

Request fields

PoleTypPopis
imagefileJPEG/PNG fotka z dronu
captionstringPopisek (volitelný)
orderintPořadí v galerii (volitelný, default 0)

Response 201

{
  "id": 12,
  "image": "/media/gallery/2026/05/foto_abc.jpg",
  "caption": "Výhled na Hradčany",
  "order": 0
}
DELETE /api/photos/{id}/ Smazání fotky z galerie Autor článku ▶

Response: 204 No Content. Pouze autor článku nebo staff.

Formáty odpovědí

HTTP stavové kódy

KódSituace
200Úspěch (GET, PATCH)
201Vytvořeno (POST)
204Smazáno (DELETE)
400Validační chyba
401Chybí nebo expiroval JWT token
403Přihlášen, ale nemá oprávnění (cizí článek)
404Zdroj neexistuje
429Rate limit překročen

Curl příklady

# Přihlášení
curl -X POST http://localhost:8001/api/auth/login/ \
  -H "Content-Type: application/json" \
  -d '{"username":"ivan_dron","password":"dron1234"}'

# Získání článků
curl http://localhost:8001/api/posts/?search=Praha

# Vytvoření článku (s tokenem)
curl -X POST http://localhost:8001/api/posts/ \
  -H "Authorization: Bearer <access_token>" \
  -F "title=Nový článek" \
  -F "content=Text článku..." \
  -F "status=published" \
  -F "location=Brno, CZ" \
  -F "altitude=80" \
  -F "drone_model=DJI Mini 4 Pro"
