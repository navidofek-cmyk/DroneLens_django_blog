Přehled architektury

DroneLens používá oddělený backend a frontend (decoupled architecture):

  • Django backend — pouze REST API (žádné šablony). Vrací JSON.
  • React SPA — celý UI v prohlížeči. Komunikuje s backendem přes fetch/axios.
  • Nginx (produkce) — reverzní proxy, obsluhuje statické soubory a přeposílá /api/* na Django.

Tok požadavku

Veřejný článek (GET)

  1. Uživatel otevře /post/praha-z-vysky v prohlížeči
  2. React Router renderuje komponentu PostDetail
  3. TanStack Query pošle GET /api/posts/praha-z-vysky/
  4. Django DRF vrátí JSON s článkem, komentáři a galerií
  5. React zobrazí stránku, TanStack Query cachuje odpověď (5 min)

Přihlášení + vytvoření článku

  1. Uživatel vyplní login formulář, React volá POST /api/auth/login/
  2. Django vrátí {access, refresh}, AuthContext uloží do localStorage
  3. Uživatel vyplní PostForm a odešle POST /api/posts/
  4. Axios přidá Authorization: Bearer {access} automaticky
  5. Django ověří token, uloží článek, vrátí 201 Created
  6. React Router přesměruje na detail nového článku

JWT refresh flow

  1. Access token vyprší (5 minut), server vrátí 401 Unauthorized
  2. Axios interceptor zachytí 401, pošle POST /api/auth/refresh/ s refresh tokenem
  3. Pokud refresh uspěje — uloží nový access token, opakuje původní požadavek
  4. Pokud refresh selže (token expiroval) — smaže tokeny, přesměruje na /login

Vrstvy backendu

Models

ORM modely: Post, Category, Tag, Comment, Photo. Auto-slug z titulu.

Serializers

6 DRF serializerů. PostListSerializer (lightweight) vs PostDetailSerializer (plný). PostWriteSerializer pro create/update.

Views

11 generic views (ListCreateAPIView, RetrieveUpdateDestroyAPIView…). Throttling na register a login.
