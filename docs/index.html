Co to je?

DroneLens je full-stack webová aplikace, kde pilot dronu může publikovat fotografie pořízené dronem, zaznamenat GPS lokaci, výšku letu a model dronu. Čtenáři mohou procházet články, filtrovat podle kategorií a tagů, a komentovat příspěvky.

Projekt byl navržen jako vzdělávací příklad moderního Django + React stacku s pokrytím celého vývojového cyklu: od lokálního vývoje přes Docker po CI/CD pipeline.

Klíčové funkce

📸 Drone fotoblog

Každý článek může obsahovat GPS lokaci, výšku letu a model dronu. Data se čtou automaticky z EXIF metadat.

🔐 JWT autentizace

Access token (5 min) + refresh token (7 dní). Axios interceptor automaticky obnovuje token při 401.

🛡️ Rate limiting

DRF throttling: 10 přihlášení/min, 5 registrací/hod. django-ratelimit na citlivých endpointech.

🐳 Docker ready

Oddělené docker-compose pro vývoj (SQLite + Vite HMR) a produkci (PostgreSQL + Nginx + Gunicorn).

🧪 Komplexní testy

93 Django testů (99 % pokrytí kódu), 40+ React testů s MSW mock serverem pro simulaci API.

☁️ S3 storage

Produkce ukládá obrázky do AWS S3 (nebo kompatibilního) přes django-storages. Lokálně MEDIA_ROOT.

Rychlý start

Celý projekt lokálně nastartujete třemi příkazy:

# Backend
cd django_blog
uv sync
uv run python manage.py migrate
uv run python manage.py runserver 8001

# Frontend (nový terminál)
cd frontend
npm install
npm run dev

→ Aplikace běží na http://localhost:5173

→ Podrobný návod: Rychlý start
